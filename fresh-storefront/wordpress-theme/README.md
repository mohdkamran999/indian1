# IHS Heritage — WordPress + WooCommerce theme

A responsive theme starter for Indian Handicraft Standards. It uses broad ecommerce patterns seen in the reference store—category-led navigation, product discovery and featured collections—but does not copy its proprietary code, images, product descriptions or branding.

## Included
- IHS ivory, navy, antique-gold and maroon styling
- Responsive header, navigation, footer and homepage
- WooCommerce support and featured product shortcode
- Customizer fields for announcement text and WhatsApp number

## Install on staging
1. Create a staging or temporary WordPress installation in Hostinger. Do not change the live domain yet.
2. Install and activate WooCommerce.
3. Zip the ihs-heritage directory itself (the folder containing style.css, functions.php, header.php, footer.php, front-page.php and index.php).
4. In WordPress Admin → Appearance → Themes → Add New → Upload Theme, upload the ZIP and activate it on staging.
5. Add the IHS logo under Appearance → Customize → Site Identity.
6. Set the Primary Menu, WhatsApp number, announcement text, shipping zones, tax settings, INR currency and payment gateway.
7. Create product categories and upload IHS-owned product images and accurate details.

## Launch checklist
- Back up existing website files and database.
- Test mobile/desktop pages, search, categories, product variations, cart, checkout, coupons, shipping/tax calculation, payment success/failure, emails, refunds, stock decrement, order status and tracking.
- Verify SSL, privacy/terms/returns/shipping pages, contact details and performance.
- Connect Meta/WhatsApp through an approved WooCommerce catalogue/feed integration and verify product IDs/variants.
- Connect Google Merchant Center using Google for WooCommerce; verify domain, shipping, tax and product feed diagnostics.
- Switch the domain only after tests pass and keep a rollback backup.

This is a theme starter, not proof of a deployed or fully tested ecommerce site. Payment gateway, catalogue connections, real products, policies and staging deployment must be configured and tested separately.
