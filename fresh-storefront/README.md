# IHS Fresh Storefront (preview)

This is a fresh, independent storefront concept for Indian Handicraft Standards, built on the `fresh-storefront` branch. It does not replace the current live website.

## Current phase
- Responsive premium storefront concept (ivory, navy, antique gold and maroon accents)
- Collection landing sections for Chikankari kurtis, palazzo sets, suits/dupattas and pants
- WhatsApp contact entry points
- Mobile-friendly layout and basic navigation

## Important limitations in this first scaffold
- The images are editorial placeholders and must be replaced with approved IHS product photography.
- Product links, bag, checkout, customer accounts, order tracking, inventory and admin are not connected yet.
- WhatsApp links open a general chat and should be updated to the verified IHS business number.
- No payment, catalogue, Meta or Google integration is represented as connected.
- Do not point the live domain at this scaffold yet.

## Next implementation phases
1. Review and approve the visual direction.
2. Build the product catalogue and admin interface with no-code-style forms.
3. Add secure authentication, product/variant/inventory/order storage and image uploads.
4. Configure Razorpay and shipping/order workflows.
5. Connect WhatsApp, Meta Commerce and Google Merchant Center feeds.
6. Test storefront, admin, order creation, mobile layouts and deployment before switching the domain.

## Preview
Open `index.html` in a browser or serve this folder as static files. The main project uses Hostinger Node.js, so this folder is a design scaffold, not yet a deployable replacement for the production app.
